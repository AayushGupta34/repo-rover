# RepoRover benchmark results

Generated by `reporover bench` on 2026-11-14. Reproduce with the same command; it needs no network, API key or database.

## Technical Strength

On 3 synthetic fixture apps with 74 hand-labelled flaws, RepoRover's deterministic stage scored 90.0% precision, 85.1% recall and an F1 of 0.875 (89.1% / 87.5% / 0.883 when process and operations rules are excluded). Every one of the 64 code locations it cited was re-opened and checked against the source, giving a measured hallucination rate of 0.0%, because findings are produced by rules over the code and the language model is only asked to judge them. These figures come from small fixtures written by the project's authors and measure the detector stage only, so they show that the pipeline is grounded and reproducible, not how it performs on arbitrary real-world repositories.

## Method and limits

- The catalogue has 143 entries; the benchmark runs its regex, absence and manifest detectors.
- Ground truth is in each fixture's `expected.json`: every flaw judged present, with its location, and every reported rule judged not present, with the reason.
- Labels were written by the same people who wrote the detectors and the fixtures. Treat the scores as a regression baseline, not an independent evaluation.
- Rules labelled `incidental` (for example no CI, no tests) are true of the fixtures but trivially so; the code-level row excludes process and operations rules.
- False negatives are kept as found. In particular `jwt-hardcoded-secret` is missed in `express_api` because its pattern does not span an object literal; it is left unfixed here so the benchmark is not tuned to its own test set.
